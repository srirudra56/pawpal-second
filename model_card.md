# Model Card: PawPal+ AI Pet Care Assistant

## Model Name

**PawPal+ AI Pet Care Assistant**

---

## Purpose

PawPal+ AI Pet Care Assistant is a Retrieval-Augmented Generation (RAG) application that provides general pet-care recommendations by retrieving information from a structured local JSON knowledge base. The system is designed to help pet owners find guidance on topics such as grooming, feeding, exercise, hydration, sleep, playtime, medication, and routine vet visits.

The application is intended to provide general educational information and is **not** intended to replace professional veterinary advice.

---

## Limitations and Biases

The PawPal+ AI Pet Care Assistant uses a local JSON knowledge base, so it can only answer questions about the topics stored within that file. If a user asks about a topic that is not included, the system cannot provide a recommendation.

The application currently supports only dogs and cats. It also relies on exact topic matching instead of semantic search, meaning users must select or enter topics that closely match those in the knowledge base. Additionally, the confidence scores are predefined for demonstration purposes and are not generated by a trained machine learning model.

---

## Potential Misuse and Prevention

One potential misuse is relying on the application for medical advice instead of consulting a licensed veterinarian. Since the knowledge base contains only general pet-care guidance, the system is not designed to diagnose illnesses or recommend treatments.

To reduce this risk, the application includes several guardrails:

- Validates required user input.
- Prevents unsupported species from being processed.
- Handles missing knowledge base files safely.
- Displays a message when no matching guidance is found.
- Includes a disclaimer encouraging users to consult a veterinarian for medical concerns.

These safeguards help ensure the system is used as an educational resource rather than a replacement for professional veterinary care.

---

## Reliability Reflection

Testing the application showed how important input validation is to building reliable AI systems. Small issues such as missing pet names, unsupported species, or unavailable topics could easily lead to confusing behavior if they were not handled properly.

The project includes automated unit tests that verify the original PawPal+ scheduling functionality. Additional manual testing confirmed that the RAG system successfully retrieves the correct guidance for supported topics while handling invalid inputs appropriately. Adding guardrails, confidence scores, and logging significantly improved the system's reliability and made debugging much easier.

---

## AI Collaboration

I used ChatGPT throughout the development process to brainstorm ideas, design the Retrieval-Augmented Generation (RAG) workflow, debug Python and Streamlit code, and improve the overall organization of the project. I reviewed every suggestion, modified it when necessary, and tested each implementation before integrating it into the final application.

### Helpful AI Suggestion

One of the most helpful suggestions was implementing a local JSON knowledge base for the Retrieval-Augmented Generation (RAG) system. This allowed the application to retrieve pet-care guidance before generating recommendations, making the responses more consistent, explainable, and easier to update without changing the application logic.

### Flawed AI Suggestion

One suggestion that was not appropriate was restructuring much of the original PawPal+ project into an entirely new architecture. This would have required rewriting large portions of already functioning code. Instead, I preserved the original scheduling system and integrated the RAG functionality into it, resulting in a simpler, more maintainable solution.

---

## Future Improvements

Future versions of PawPal+ AI Pet Care Assistant could include:

- Natural language questions instead of selecting predefined topics.
- Semantic search using embeddings instead of exact keyword matching.
- A larger knowledge base supporting additional pet species.
- Personalized recommendations based on pet age, breed, weight, activity level, and medical history.
- Integration with veterinary resources and appointment reminders.
- Smarter confidence scoring based on retrieval quality instead of predefined values.

---

## Overall Reflection

This project helped me understand how Retrieval-Augmented Generation combines information retrieval with AI-generated responses to create more reliable and explainable systems. It also reinforced the importance of software engineering practices such as modular design, testing, logging, and input validation when building AI applications.

Developing PawPal+ AI Pet Care Assistant showed me that combining traditional programming with AI techniques creates applications that are more trustworthy, easier to maintain, and more useful for end users.
